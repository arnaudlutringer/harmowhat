Musyng Kite SoundFont, instrument « cello »

Fichiers non modifiés, téléchargés par `npm run samples` (scripts/fetch-samples.mjs).
Le volume est équilibré dans le code (src/audio/instruments.ts).

Les fichiers sont renommés par numéro MIDI (69 = La3/A4 = 440 Hz),
un échantillon toutes les tierces mineures sur la tessiture de l'instrument.
